# TRACE HQ (archived)

A first-person 3D walkthrough of an IAM engineer's workday, built for ammakwarteng.com and
retired from the public site in November 2026 when the portfolio moved to the
"A Living Identity" direction. Nothing here is published: Vite only deploys `public/`.

- `site/`: the standalone page (Three.js r160 vendored, door, chair and keyboard models with credits)
- `screenshots/`: the six gallery images from its project card
- `project-card.js`: the project card data

Credits for the 3D models are in `site/index.html` (CC BY 4.0).
